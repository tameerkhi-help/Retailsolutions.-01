# Vibevault – Enterprise Retail Operations Platform

**Vibevault** is a fully responsive, production‑ready brand website for an enterprise retail operations company. It showcases human‑powered back‑office management solutions, including POS configuration, CCTV surveillance, inventory control, and daily reconciliation.

> **Live Demo:** [https://vibevault1.store](https://vibevault1.store)

---

## ✨ Features

- **Modern, Premium UI** – Dark navy/cyan gradient theme, floating badges, and smooth animations.
- **100% Responsive** – No horizontal scrolling, no text clipping on any device.
- **10 Client Testimonials** – Carousel with star ratings, author photos, and verified badges.
- **Interactive Carousels** – Features and testimonials with auto‑scroll and dot navigation.
- **FAQ Accordion** – Expandable answers to common questions.
- **Lead Capture Forms** – On the homepage and contact page (with Firebase integration).
- **Advanced SEO** – Canonical tags, Open Graph, Twitter Cards, and JSON‑LD structured data.
- **Inline SVG Favicon** – Works in all browsers and search results.
- **Firebase Realtime Database** – Contact form submissions are stored securely.
